# 游戏玩法总结（玩家视角）


## 一、游戏类型与核心玩法


这是一款 **3D 俯视角回合制策略战棋游戏**，采用**双人同屏热座对战**模式（红方 vs 蓝方，两人在同一台电脑上轮流操作，没有单人 AI 对手）。玩家在一张带海洋、道路、桥梁的方形格子小地图上，指挥己方的坦克部队**移动、攻击、占领建筑**，用建筑产生的收入**购买增援**，目标是歼灭对方所有部队并夺取其所有建筑。


## 二、操作方式


游戏全程以鼠标为主：


| 操作 | 功能 |
|---|---|
| 左键点击己方坦克 | 选中，黄色高亮显示可移动范围 |
| 鼠标悬停格子 | 实时预览行军路线（路线上有箭头指示）；右下角显示该格的地形/建筑信息 |
| 左键点击范围内格子 | 下令移动，坦克沿路线行进 |
| 移动完成后 | 在坦克旁弹出行动菜单：开火 / 占领 / 待命（按情境显示） |
| 悬停/点击敌人 | 选中攻击目标时显示准星，点击确认后开战 |
| 左键点击空地（未选中任何单位时） | 弹出菜单：结束回合 / 选项 |
| 左键点击己方基地 | 弹出购买菜单 |
| **右键** | 万能“取消”：关闭菜单、撤销尚未确认的攻击、撤销本次移动（坦克退回原位）、取消选中 |
| 滚轮 | 缩放镜头 |
| WASD / 方向键 / 鼠标移到屏幕边缘 | 平移镜头 |


屏幕顶部中央会随时提示当前按键含义（左键=确认/菜单，右键=取消），左上角横幅显示当前行动方（红/蓝）。


## 三、游戏流程（从开始到结束）


1. **标题画面**：只有“开始游戏（双人热座）”和“退出”两个选项。
2. **进入地图**：首先显示一段教学文字（占领全部敌方建筑并消灭其坦克；在基地造坦克；占领需要连续多回合重复执行“占领”指令；停在己方建筑上可以回血），点击任意处关闭。
3. **“第 1 天”横幅**闪现，红方先行。
4. **己方回合内**可依次操作所有坦克：移动 → 攻击/占领/待命；已行动过的坦克会**变灰**，本回合不可再用。也可点击基地购买新坦克，或点击空地选择“结束回合”。
5. 回合结束时会**结算收入**，然后镜头交给对方，“第 N 天”横幅再次出现（双方各行动一次为一天，天数+1）。
6. 回合开始时，停在己方建筑上的坦克**自动回血**。
7. 一方**同时失去所有建筑和所有坦克**时对局立即结束：屏幕变暗，中央显示“红方获胜！”/“蓝方获胜！”的大字，点击“退出地图”返回标题画面。


## 四、核心系统


- **回合/天数系统**：双方轮流行动，回合数以“天”计；己方单位每回合刷新一次行动机会。
- **经济系统**：初始资金 8000，每回合结束时**每拥有 1 座建筑收入 +3000**；资金显示在屏幕上方。
- **生产系统**：只有**基地**能生产，且目前只有一种单位——坦克（6000 一辆）；资金不足时购买项变灰不可点。新坦克造出后当场就算已行动。
- **战斗系统**：坦克满血 10 点，只能攻击**紧邻（含斜向）一格**内的敌人。伤害与自身当前血量挂钩：**攻击方造成约自身血量一半的伤害，防守方反击只造成约两成的反伤**——满血主动进攻非常占便宜，残血单位几乎失去威慑力。受损单位头顶显示剩余血量数字（满血不显示），被摧毁时有爆炸特效和音效。
- **占领系统**：建筑有 20 点耐久。坦克停在敌方/中立建筑上选择“占领”，每次削减的耐久等于坦克**当前血量**——满血坦克也要占两个回合，残血坦克需要更久，且**每个回合都要重新下达“占领”指令**。占领成功后建筑立即变色归己；无人争夺的己方建筑每回合缓慢恢复耐久。建筑分**城市**（提供收入+驻扎回血）、**基地**（收入+造兵+回血）、**总部**（己方核心建筑）三类。
- **休整系统**：回合开始时，停在己方建筑上的坦克回血——城市 +1、基地 +2，上限 10。
- **地形系统**：平原、道路、海洋（**不可通行**）、桥梁（跨越海洋的通道）；建筑上驻有单位时建筑会变半透明，方便点选。
- **撤销机制**：移动后、行动确认前，右键可让坦克退回出发点重新决策，容错度较高。


## 五、难度曲线


游戏**本身不提供难度设计**——没有 AI、没有战役关卡、没有难度选项，挑战完全来自对面的人类玩家。但在一局对战内部存在明显的**经济滚雪球曲线**：开局资金只够买一辆坦克，随着占领建筑增多，收入差距会迅速拉大部队规模差距，先手方（红方）也略有行动优势；一旦一方经济被压制，很难翻盘。因此对局通常呈现“前期精打细算 → 中期扩产压制 → 后期一边倒”的走势。


## 六、胜利 / 失败条件


- **失败方**：当一方**既没有剩余建筑、也没有剩余坦克**时立即判负（只占其一仍可继续挣扎）。
- **胜利方**：另一方随即获胜，结算画面宣告获胜阵营，之后只能退出地图回到标题。没有平局、回合数上限或加分机制。
